## 🧩 What is Pandas?
Pandas is a fast, flexible, and powerful Python library used for:
- Data cleaning  
- Data manipulation  
- Data analysis  
- Working with CSV, Excel, JSON, SQL, and more  
- Handling tabular + labeled data  

Pandas introduces two main data structures:
1. **Series** → 1-D labeled array  
2. **DataFrame** → 2-D table (rows × columns)
